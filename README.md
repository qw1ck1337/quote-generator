
# ✨ Random Quote Generator — Генератор случайных цитат

**Автор:** Ваше Имя и Фамилия

## Описание

Приложение для генерации случайных вдохновляющих цитат. Сохраняет историю всех сгенерированных цитат, позволяет фильтровать по автору и теме, добавлять свои собственные цитаты.

## Возможности

- 🎲 Генерация случайной цитаты из предопределённого списка
- 📝 Добавление своих цитат
- 📜 История всех сгенерированных цитат (с датой и временем)
- 🔍 Фильтрация истории по автору и теме
- 💾 Сохранение истории в JSON
- 📊 Статистика использования
- ✅ Валидация ввода (пустые поля)
